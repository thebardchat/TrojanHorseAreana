## R-006.1 — Who is the AHJ?
QUESTION: Which office permits and inspects a privately built arena in Hazel Green?

ANSWER: Hazel Green is **unincorporated** (S5), and the county permit portal covers "the unincorporated areas of Madison County" (S4), so on a Hazel Green parcel outside any city limits the building AHJ is the **Madison County Inspection Department** (266-A Shields Road, Huntsville; commercial permits under the county's Commercial Construction Resolution, S1/S3). The county states there are **no zoning limits** on construction projects or signs, but the building, fire and trade codes apply (S3). If the parcel (D-006) falls inside a city (e.g. annexed land), that city becomes the AHJ — not researched. Separately: **DCM's State Building Code does not cover private commercial buildings** except hotels/motels, movie theaters and **schools**, and DCM's "schoolhouse" definition includes "any private building in which 25 or more persons are congregated regularly for the purpose of instruction in any branch of knowledge" (S7, 355-12-1-.04(1)(b)). Whether regular youth-wrestling practice / clinics count as "instruction" is **not settled here → ask DCM and the county** (it would add DCM plan review under the 2021 IBC). An assembly building also **requires a registered architect regardless of size** (S8).

## R-006.2 — Which code editions?
QUESTION: Which code editions apply to the Phase 2 building?

ANSWER: **Madison County enforces (since 2021-01-01): 2018 IBC, IRC, IEBC, IPC, IMC, IFGC, ISPSC; 2018 IFC; 2018 NFPA 101 Life Safety Code; 2017 NEC; 2015 IECC (state mandate)**, with local amendments in its resolution of 2020-09-02, and says **no code changes are planned in the next 12 months** (S1, S2, S3). The **State Fire Marshal** has adopted the **2021 IFC** (Appendices B, C, D, E, M; D107 and M recommended only) for projects whose architectural services contract is dated on or after the rule's effective date (S6) — so the fire code edition can differ from the county's building code edition. **KEYSTONE has been designing to IBC 2021 (Shane; UpCodes Alabama text).** Conflict flagged: county building code = 2018 IBC + 2018 NFPA 101; state fire code = 2021 IFC. Recommendation: keep designing to IBC 2021 (the newer text), check every egress / fixture / seating number against the 2018 IBC and NFPA 101 (2018) chapter 12 (new assembly) before the permit set, and confirm the editions at the pre-application meeting (D-008). Factors KEYSTONE has used so far (Table 1004.5, 1005.3.1, 1011, 1030) were read in the 2021 text only; 2018 equivalence is NOT verified, and NFPA 101 can be more restrictive for large assembly occupancies (not reviewed).
