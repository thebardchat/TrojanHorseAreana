# Logos

The THA (Trojan Horse Arena) mark lives in `blueprints/brand/` and is not duplicated here, so there is one copy to keep current.

| File | Ink | Use on |
|---|---|---|
| `blueprints/brand/THA_logo_red.svg` | #cc0000 (`school-red`) | paper or light grounds |
| `blueprints/brand/THA_logo_white.svg` | #ffffff | dark grounds, `brand` fills |
| `blueprints/brand/THA_logo_black.svg` | #1a1a1a (`school-black`) | one-color print |

Each file is a fixed fill. Do not recolor or redraw the mark.
