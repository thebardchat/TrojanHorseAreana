The square, uppercase, monospace action button from the arena web pages, in a solid primary and an outlined ghost form.

**When to use:** one primary per view for the main action ("View on GitHub"); ghost for secondary links beside it.

**Rules**
- Primary: `brand` fill, `on-brand` text, `glow-brand` shadow, no border. On hover lift 2px and brighten.
- Ghost: transparent, 1px `border`, `ink` text; on hover border and text turn `brand`.
- Type is `arena-button` (uppercase, 0.1em tracking). Padding `space-3` by `space-8`. Radius `radius-sharp`.
- Buttons sit in a row with `space-4` between, wrapping on narrow screens.

**The consumer supplies** the label and the link target.
