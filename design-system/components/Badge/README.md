The outlined accent badge that tags a hero or status, set in `arena-label` type.

**When to use:** once, above the hero title, to name the program or state ("ShaneBrain Ecosystem"). Not for counts or inline status.

**Rules**
- 1px `accent` border, `accent` text, transparent fill, `radius-sharp`.
- Padding 4px by 14px (source: 0.25rem by 0.9rem). Uppercase with 0.2em tracking.
- The only animation in the system: a 2s pulse of `glow-accent` on arena. Turn it off on paper and for reduced motion.
- On paper the accent is a gold fill that fails text contrast: there, use a `brand` outline and `brand` text instead.

**The consumer supplies** the label text.
