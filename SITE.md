# Site: how it updates

`index.html` is a fixed shell. Everything that changes lives in `updates.json` (hero image, direction text, update feed, gallery, upcoming list, documents). Push to `main` and `.github/workflows/deploy.yml` publishes ONLY the public site files (index.html, updates.json, hazel-green-complex-3d.html, concepts/) to Cloudflare Pages (`trojan-horse-arena`). Everything else in the repo (blueprints/, research, decisions, status, cost notes, the Set Rev D PDF, whose cover prints the planning budget range) is never served; add a path to the `Assemble public site` step to publish it.

```
python add_update.py "Title" "What changed." --tag Concept --image concepts/new.png     # new update card
python add_update.py --gallery concepts/new.png "Title" "Caption."                       # new gallery image
python add_update.py --upcoming "Title" "What is next." --status Open                    # new upcoming item
git add -A && git commit -m "site: <what>" && git push origin main
```

Concept images are generated by `render_revD_srm_concept.py`, `render_srm_concept_interior.py`, `render_srm_concept_plan.py` and `render_revD_views.py` into `concepts/`.

Rules: keep the PRELIMINARY stamp; do not publish budget figures, owner-only planning numbers or any claim of an agreement with a named company; no company logos or marks without written permission. The approved set stays `blueprints/phase2/out/pdf/Phase2_Schematic_Set_RevD.pdf` (not published); concept work never overwrites it.
